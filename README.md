# דפ"ר עילאי: אפליקציית הכנה

אפליקציית תרגול להכנה לדפ"ר (הדירוג הפסיכומטרי הראשוני לפני הגיוס). המבחן ב-29.10.2026. המטרה: שליטה בחומר בשלוש שכבות (ידע, הבנה, יישום), ומדידה של הטעויות החוזרות.

## מה יש בריפו

- CLAUDE.md: הוראות קבועות ל-Claude Code. נקראות לפני כל שינוי.
- docs/01-spec.md: אפיון המוצר, מסלולי המשתמש, מה נכנס למוצר המינימלי ומה לא.
- docs/02-learning-model.md: מודל השליטה, כללי התחומים, סוגי הטעויות והתרופה לכל סוג.
- docs/03-study-plan-9-days.md: תוכנית יומית של שעה, מ-21.10 ועד 29.10.
- docs/04-data-model.md: טבלאות Supabase והרשאות.
- docs/05-screens.md: מסכים, ניווט עליון, ומצבי מערכת.
- prompts/build-prompt.md: הפרומפט לבנייה ב-Claude Code, צעד אחר צעד.
- supabase/migrations/0001_init.sql: הסכמה הראשונית.
- data/question-bank.template.json: תבנית לשאלה אחת. אין כאן שאלות רשמיות.

## סדר עבודה מומלץ

1. לקרוא את CLAUDE.md ואת docs/01 ו-docs/02.
2. להריץ את הפקודה uipro init --ai claude בתיקיית הריפו.
3. להעתיק את הפרומפט מ-prompts/build-prompt.md ל-Claude Code.
4. להריץ את מיגרציית Supabase.
5. לבדוק את האפליקציה בנייד ובמחשב לפי הרשימה ב-docs/05.

## מה עדיין פתוח

- קישור "שיחת הפיתוח" ו"פרויקט המחקר": מוגדרים כערכים TBD בקובץ src/config/links.ts עד שיימסרו.
- פרק האנגלית: לא מופיע בהנחיית המומחה. יש לבדוק מול הנוסח הרשמי של המבחן האם הוא כלול.
- תאריך ושעת המבחן: לאמת מול הנוסח הרשמי.
- יעד הציון: 90 כברירת מחדל.
